THRONE][OS™ is an Android security layer by Infinitum Corporation®. The public edition on this page is ARCH//ANGEL.

Public edition · ARCH//ANGEL · Android 10 and later

OVERVIEW
Android security layer

ARCH//ANGEL is a monochrome, minimalist launcher for the phone you already have. It opens the Infinitum suite from one home screen, checks how the device is hardened, and keeps messages encrypted in THRONE Vault.

This page is the universal Android download. It is separate from #THRONE™ computers.

01 / THE PUBLIC EDITION

What ARCH//ANGEL includes.

  • Launcher

    A monochrome, minimalist launcher with the Infinitum suite on the home screen.

  • THRONE Guard

    A device-hardening audit. It checks app permissions, camera and microphone access, an always-on VEIL</>™ VPN, Private DNS, and secure messaging.

  • THRONE Vault

    Encrypted messages using AES-256-GCM and X25519.

04 / INSTALL

From the browser to the home screen.

  1. Allow install from the browser

    Android blocks installs that start in a browser until you allow that browser. Open Settings, then Apps, then Special app access, then Install unknown apps. Select the browser you used to download the package and turn on Allow from this source.

  2. Install the APKs

    Open each downloaded APK and confirm the install. If the release includes more than one package, install every APK before you leave this step.

  3. Set THRONE as Home

    Open Settings, then Apps, then Default apps, then Home app, and choose THRONE. The monochrome launcher becomes the home screen.
