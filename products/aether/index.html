OVERVIEW
Military use only

ÆTHER MIL™ keeps units talking, navigating and sharing data when networks are jammed, damaged or absent. Every device is managed by the customer, every message is end-to-end encrypted, and every server and gateway belongs to the military organization that runs it.

There is no commercial edition. ÆTHER MIL™ is sold only to authorized military and defense organizations as part of ODIN°™, runs on closed, accredited infrastructure and sits outside the token economy. For private communications outside defense, Infinitum offers FabriC++™.

02 / SECURE VOICE, TEXT & DATA

Every message protected. Every word understood.

ÆTHER MIL™ carries all secure voice, text and data inside ODIN°™, from a squad's push-to-talk group to a headquarters video call, over whatever path is available.

  • End-to-end encrypted

    Messages, voice, video and files are protected between devices, with keys held only on organization-controlled hardware.

  • AI that stays on the device

    Thread summaries, live call translation and suggested replies run on the device, so conversations never leave the network.

  • One identity, one directory

    Every user signs in once with an organization-issued Cumulus://ID MIL™ credential and reaches any unit at its internal address.

  • Works over any path

    Over government networks, Wi-Fi, approved radios or the ÆTHER Mesh™ when there is no network at all.

  • Rotating burner numbers

    Disposable numbers that hide a user's real number and rotate automatically on a set schedule or after each mission, so no number stays in use long enough to be tracked. Added in bundles of 1, 2 or 5, renewed monthly or yearly.

  • Mission records

    Approved conversations and files can be preserved with a tamper-evident chain of custody on Firmament Network MIL™.

  • Never sold

    Mission data is never licensed, sold or used for advertising, and ÆTHER MIL™ sits outside the token economy.

03 / CAPABILITIES

ÆTHER MIL™ capabilities.

Secure voice, text & data · Digital radio · Field mesh · Offline GPS · Secure talk · Private servers · Device control

COMMUNICATIONS

Encrypted individual and group messaging, controlled push-to-talk groups, secure voice conferencing, authenticated users, and offline message delivery when connectivity returns.

FIELD NETWORKING

Portable ÆTHER™ nodes, authenticated multi-hop connections, local network discovery, store-and-forward communications, and optional connectivity through approved external gateways.

NAVIGATION

Downloadable topographic maps, offline GPS, coordinate systems for authorized users, private waypoint storage and controlled location sharing.

RADIO INTEGRATION

Interfaces for compatible military-approved digital radio hardware, under vendor agreements, radio-frequency authorization and security certification. Conventional analog FM broadcasting is not inherently encrypted.

DEVICE SECURITY

Organization-controlled Android devices, hardware-backed key protection, remote credential revocation, verified software updates, and policies for lost or compromised devices.

INDEPENDENT HOSTING

Military customers run their own ÆTHER™ servers and mesh gateways, without routing sensitive information through Infinitum's commercial cloud.

ADMINISTRATIVE SEPARATION

Each military customer receives isolated identity, access-control, logging and key-management environments.

Each ÆTHER MIL™ deployment goes through independent evaluation, accreditation and operational testing with the customer before operational use.
