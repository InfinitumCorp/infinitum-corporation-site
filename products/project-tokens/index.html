Project-specific tokens™

Every major Infinitum product has its own token, paired with $FIRM™ and held in $FIRM Wallet™, so each product's economy can grow on its own while staying connected to the whole.

OVERVIEW
Token framework

One universal token would blur what each product is worth. Instead, each product has a token tied to a real function: $VEIL rewards browsing, $SCLV pays for agent work, $ARCT pays for verified outcomes, $FAB shares communications revenue.

Every token pairs with $FIRM™, so value moves freely between products through the $FIRM™ DEX, and every transaction is recorded on $Firmament Network™.
